# Raw Alchemy Studio v0.6.4

This maintenance release follows up on the Windows file-dialog crashes and
GPU-status confusion reported in [#37](https://github.com/shenmintao/Raw-Alchemy/issues/37).

## Windows file dialogs

Windows now uses Qt file dialogs throughout the application, including photo
folders, LUT folders, exports and log export. This avoids the native Windows
file-dialog path implicated by the reporter's COM thread errors and access
violations. Folder/file selection, cancellation, export suffixes and overwrite
confirmation retain their existing behavior.

The reporter's crash has not yet been reproduced on their RTX 3050 Ti system;
this change needs their confirmation before the issue can be closed.

## Clearer GPU settings

- Settings now shows the preferred inference backend explicitly, such as
  **DirectML (GPU)** or **CPU**, and explains automatic CPU fallback.
- The display respects CPU-only configuration and refreshes with **Detect Again**.
  Reading the status does not initialize an inference model.
- Standard Windows portable builds use DirectML and do not require CUDA
  libraries. Their status remains **CUDA runtime not required by this build**
  even if CUDA/cuDNN libraries are already installed on the system.
- Backend detection failures are displayed separately from CPU inference.
  A preferred backend is a configuration report, not a measurement of which
  graph operators executed on the GPU.
- English and Chinese translations have been updated together.

## Downloads

- **Windows x86-64:** fully extract `RawAlchemyStudio-v0.6.4-windows-x64-portable.zip`
  into a new folder and run `RawAlchemy.exe`.
- **macOS Apple Silicon:** open the DMG and copy `RawAlchemy.app` to Applications.
  The portable app requires **macOS 26 or later**.
- **Linux x86-64:** extract the portable tarball and run `RawAlchemy/RawAlchemy`.
- `SHA256SUMS.txt` contains the archive checksums. Portable builds do not update
  automatically.

## Validation and scope

- Local Windows/Python 3.12 regression suite: **668 passed, 11 skipped**.
  The two existing Canon Log reference warnings are unchanged.
- [Hosted CI](https://github.com/shenmintao/Raw-Alchemy/actions/runs/39728528465)
  passed on Windows, macOS 15 and Ubuntu: **661 passed, 18 skipped** on each,
  including installed-wheel runtime checks, Ruff and Nikon HE/HE-star samples.
- The targeted dialog, backend settings, CUDA runtime, provider-selection,
  export-filename and UI-safety suite passed: **65 tests**. Ruff passed for
  the changed Python files.
- Startup checks exercise real Qt folder/save dialogs in a fresh process and
  verify that the application-wide dialog setting applies only to Windows.
- Backend settings cover DirectML with and without installed CUDA libraries,
  CPU-only mode, detection failures, and avoiding model initialization.
- The reporter's physical NVIDIA GPU and original crash still require
  hardware validation. Issue #37 remains open for their feedback.
