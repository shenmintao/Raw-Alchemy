# Raw Alchemy Studio v0.6.2

This maintenance release fixes single-image export filenames and fixed-lens
correction, and makes ordinary source installations include Nikon HE/HE★ decoding.

## Fixes

- **Export Current filenames ([#27](https://github.com/shenmintao/Raw-Alchemy/issues/27)).**
  Selecting JPEG, HEIF, HDR HEIF, TIFF or DNG now supplies the corresponding
  extension when the filename has none. Qt resolves the extension before
  checking for an existing destination, preserving overwrite confirmation.
  Explicitly entered extensions and cancellation retain their usual behavior.
- **Fixed-lens correction ([#22](https://github.com/shenmintao/Raw-Alchemy/issues/22)).**
  Compact cameras such as Sony ZV-1 can find their unique fixed-lens profile
  even when the RAW omits the lens name. This fallback is limited to the
  camera's private mount, avoiding unrelated interchangeable-lens matches.
  Correction uses the database crop factor instead of a coarse EXIF estimate
  that can prevent Lensfun from enabling the calibration. Full-image, striped
  and GPU coordinate-map paths share this behavior.
- **Automatic HE decoder installation.** `pip install .` and editable installs
  now build and install the pinned `rawpy 0.27.1+rawalchemy.he1` source dependency
  automatically. A system C++ compiler is required for the first source build;
  pip supplies the Python build tools. No separate decoder-install command is
  needed. Portable packages continue to include the ready-to-use decoder and
  require no compiler or system Python.

Nikon HE/HE★ support, camera-matrix recovery, preview zoom and export marks from
v0.6.1 are included. Lensfun remains at the verified 2026-03-25 snapshot
(0.3.99.0); its library and database have not changed in this release.

## Downloads

- **Windows x86-64:** extract the portable ZIP and run `RawAlchemy.exe`.
- **macOS Apple Silicon:** open the DMG and copy `RawAlchemy.app` to Applications.
  This portable build requires **macOS 26 or later**.
- **Linux x86-64:** extract the portable tarball and run `RawAlchemy/RawAlchemy`.
  The Ubuntu 24.04 build requires compatible glibc and desktop OpenGL/XCB libraries.
- `SHA256SUMS.txt` contains the archive checksums. Portable builds do not auto-update.

## Validation and scope

- Local Windows regression suite: **638 passed, 11 skipped**.
- [Hosted CI](https://github.com/shenmintao/Raw-Alchemy/actions/runs/39132551593)
  passed on Windows, macOS 15 and Ubuntu: **631 passed, 18 skipped** on each.
  Source compatibility on macOS 15 does not lower the portable app's macOS 26
  requirement.
- All three platforms built the enhanced decoder through normal pip dependency
  installation, matched four recorded Z8/Z50 II HE/HE★ sensor mosaics, and
  passed isolated application-wheel checks for packaged Lensfun, its database,
  fixed-lens correction, ONNX CPU inference and Qt.
- Both original RAW files from #22 (ZV-1 ARW and PEN-F/14–150mm ORF) were exported
  with correction enabled. The save-dialog format, explicit-extension and cancel
  cases have regression coverage.
- A completely new Windows environment successfully ran `pip install .` and
  passed the four HE/HE★ mosaic checks and `pip check`.
- Issue #34 still needs its original DNG for file-specific verification;
  the reported macOS 27 beta startup problem (#32) has not been reproduced on
  a matching beta system. CANS / AI demosaic-denoise remains disabled pending
  quality acceptance.
