# Raw Alchemy Studio v0.6.5

This maintenance release fixes the colour corruption after editing reported in
[#38](https://github.com/shenmintao/Raw-Alchemy/issues/38).

## Stable colours after adjustments

Some RAW files, including the supplied Xiaomi 14 Ultra DNG, opened with normal
colours but became discoloured after changing temperature or other adjustments.
When lens correction was enabled but could not find a usable profile, its cache
could retain the mutable processing buffer. Later colour operations or buffer
reuse overwrote the cached linear pixels, affecting subsequent edits, metering
and cached exports.

Skipped lens corrections now preserve an independent copy whenever their result
shares the processing buffer. Full-resolution and proxy caches retain linear
pixels across adjustments and resets, including when the output cache is evicted.
Successful lens corrections that already produce independent pixels keep their
existing allocation behaviour. The fix applies to both fused and per-operation
colour processing and does not require CUDA.

## Downloads

- **Windows x86-64:** fully extract `RawAlchemyStudio-v0.6.5-windows-x64-portable.zip`
  into a new folder and run `RawAlchemy.exe`.
- **macOS Apple Silicon:** open the DMG and copy `RawAlchemy.app` to Applications.
  The portable app requires **macOS 26 or later**.
- **Linux x86-64:** extract the portable tarball and run `RawAlchemy/RawAlchemy`.
- `SHA256SUMS.txt` contains the archive checksums. Portable builds do not update
  automatically.

## Validation

- Reproduced the cache corruption with the reporter's original
  `IMG_20260313_095519.dng` using CPU inference, then verified normal rendering
  after repeated temperature changes with the fix.
- Added **14 regression cases** covering full-resolution and proxy rendering,
  fused and per-operation processing, adjustments and resets, missing EXIF,
  unavailable lens profiles, correction errors and aliased tiled results.
- Local Windows/Python 3.12 suite: **682 passed, 11 skipped**. The two existing
  Canon Log reference warnings are unchanged. Ruff passed for all tracked Python
  files and the new regression file.
