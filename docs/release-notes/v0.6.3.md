# Raw Alchemy Studio v0.6.3

This release improves CUDA runtime discovery and local installation for
[#37](https://github.com/shenmintao/Raw-Alchemy/issues/37), updates the Lensfun
camera/lens database, and adds Homebrew installation for macOS.

## CUDA runtime settings

- **Detect before downloading.** Settings checks the application's local
  runtime, CUDA/cuDNN environment variables, standard installation directories,
  loader paths and NVIDIA Python packages. CUDA and cuDNN can reside in separate
  directories. When all required libraries are found, the download/import
  buttons are hidden and the detected paths are displayed. Downloading also
  checks again before making a network request.
- **Import a downloaded package.** On CUDA-enabled builds, choose **Settings →
  GPU Acceleration → Import Local CUDA Package** and select the runtime ZIP or
  tarball. Libraries inside nested folders are placed in the application's
  runtime directory automatically. Manual extraction is unnecessary.
- **Explain missing dependencies.** A CUDA Toolkit installation without the
  required cuDNN libraries is reported as incomplete, with the missing filenames.
  **Detect Again** refreshes the result after installing system libraries.
- **Validate before replacing.** Incomplete, corrupt or cancelled imports leave
  the existing local runtime untouched. Downloaded packages pass the same
  validation before installation succeeds. Restart the application after
  installing a runtime.
- **Clarify DirectML builds.** The standard Windows portable package uses
  DirectML/CPU and displays that CUDA libraries are unnecessary. Import/download
  controls are available only with a compatible NVIDIA GPU and a CUDA-enabled
  ONNX Runtime build. Installing runtime libraries does not change the inference
  backend included in the application.

## Other updates since v0.6.2

- Lensfun now uses upstream development revision
  `43f9e001ab66c4fcdd4f400463f13b72f94b2288` (2026-10-08), including updated
  profiles such as Sony ZV-1A and Nikkor Z DX 16–50mm f/2.8 VR. Native library
  version remains 0.3.99.0. See the
  [database provenance and validation](https://github.com/shenmintao/Raw-Alchemy/blob/v0.6.3/docs/UPGRADE_STATUS.md).
- macOS users can install the prebuilt application using
  `brew install --cask shenmintao/raw-alchemy/raw-alchemy-studio` after
  `brew tap shenmintao/raw-alchemy`.

## Downloads

- **Windows x86-64:** extract the portable ZIP and run `RawAlchemy.exe`.
- **macOS Apple Silicon:** open the DMG and copy `RawAlchemy.app` to Applications.
  The portable application requires **macOS 26 or later**.
- **Linux x86-64:** extract the portable tarball and run `RawAlchemy/RawAlchemy`.
  Compatible glibc and desktop OpenGL/XCB libraries are required.
- `SHA256SUMS.txt` contains the archive checksums. Portable builds do not update
  automatically.

## Validation and scope

- Local Windows regression suite: **663 passed, 11 skipped**. Ruff passed for
  the changed Python files.
- Regression coverage includes split CUDA/cuDNN discovery, offline ZIP/tar
  imports, missing libraries, cancellation, preservation of an existing runtime,
  avoiding redundant downloads, settings state and progress beyond 2 GiB.
- Runtime discovery checks library files. Actual NVIDIA CUDA inference has not
  been verified on a physical NVIDIA GPU for this release; the reporter's
  RTX 3050 Ti still needs hardware validation. CUDA runtime package v1.0.0 is
  a separate version from the installed CUDA Toolkit and the application.
