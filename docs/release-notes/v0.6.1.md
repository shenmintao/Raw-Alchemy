# Raw Alchemy Studio v0.6.1

This update adds Nikon High Efficiency RAW decoding, recovers missing camera
colour matrices, and makes preview zoom and export marks easier to use.

## Nikon HE and HE★

- Portable builds include rawpy 0.27.1 with a pinned, corrected
  [LibRaw HE/HE★ decoder](https://github.com/pdcgomes/redlamp-libraw/tree/3b20539d3faa766a370e93a529a3b87edffbf0f6),
  derived from [LibRaw PR #826](https://github.com/LibRaw/LibRaw/pull/826).
- Z8 HE/HE★ and Z50 II HE/HE★ samples match the decoder's recorded mosaics
  at every sensor sample. This verifies those samples against the fork's
  references; it is not an independent Nikon/Adobe comparison for all cameras.
- When LibRaw lacks a camera matrix, the application can recover the exact
  camera's profile from its bundled camera database. Z50 II's D65 coefficients
  were checked against its Adobe Standard profile and
  [dnglab's Z50 II profile](https://github.com/dnglab/dnglab/blob/main/rawler/data/cameras/nikon/z50_mk2.toml).
- Decoder sources and checksums are pinned in `raw-dependencies.json`.
  Source installations need `python tools/build_rawpy.py --install` to enable
  HE/HE★; ordinary PyPI rawpy wheels do not include this decoder.

## Fixes and preview controls

- **Missing DNG colour matrices ([#34](https://github.com/shenmintao/Raw-Alchemy/issues/34)).**
  Zero, nonfinite and singular matrices now fall back to an embedded colour
  matrix, the bundled camera profile, or LibRaw's colour processing. Preview
  and export share the recovery logic; white balance and orientation apply once.
- **Preview zoom ([#28](https://github.com/shenmintao/Raw-Alchemy/issues/28)).**
  The main preview has Fit, 100% and an editable zoom percentage. Percentages
  account for original image dimensions and display scaling, including when
  the displayed preview uses a smaller proxy.
- **Export marks ([#28](https://github.com/shenmintao/Raw-Alchemy/issues/28)).**
  Marked thumbnails show a green border and check badge. Marks remain visible
  when thumbnails refresh in the background.
- Persistent processing caches identify the native decoder revision and camera
  database, preventing reuse of results from a different decoder/profile.

## Downloads

- **Windows x86-64:** extract the portable ZIP and run `RawAlchemy.exe`.
- **macOS Apple Silicon:** open the DMG and copy `RawAlchemy.app` to Applications;
  macOS 15 or later is required.
- **Linux x86-64:** extract the portable tarball and run `RawAlchemy/RawAlchemy`.
  The Ubuntu 24.04 build requires compatible glibc and desktop OpenGL/XCB libraries.
- `SHA256SUMS.txt` contains the archive checksums. Portable builds do not auto-update.

## Validation and scope

- Windows/Python 3.12 regression suite: **620 passed, 11 skipped**.
- Four real Nikon HE/HE★ sensor mosaics checked; Z50 II JPEG export and
  10-bit BT.2020/PQ HDR HEIF export checked.
- Native decoder build, isolated application-wheel runtime probe, Ruff and
  dependency consistency checks passed locally.
- Issue #34 did not include its original DNG, so that exact file has not been
  retested. New Linux/macOS native builds are covered by the release/CI workflows;
  local camera/export validation above was performed on Windows.
- HE support uses a community decoder. Other camera modes and files still need
  their own validation. CANS / AI demosaic-denoise remains disabled pending quality acceptance.
